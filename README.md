# پُل

یه برنامه‌ی اندروید که با شبکه‌ی Tor وصلت می‌کنه، فقط با یه دکمه.

کاری که پُل می‌کنه اینه که روش‌های مختلف Tor رو خودش پشت سر هم امتحان می‌کنه تا یکی جواب بده. لازم نیست بدونی Snowflake چیه یا obfs4 چیه، فقط دکمه رو بزن.

## چطوری کار می‌کنه

- اول از سرور خود Tor می‌پرسه که برای ایران چی جواب می‌ده و پل تازه می‌گیره
- بعد به ترتیب Snowflake، پل‌های گرفته‌شده، WebTunnel، obfs4 و meek رو امتحان می‌کنه
- هر کدوم که وصل شد یادش می‌مونه و دفعه‌ی بعد اول همونو می‌زنه
- اگه هیچی نشد، از منو «گرفتن پل از ربات تلگرام» رو بزن، توی ربات پل بگیر و Copy کن. وقتی برگردی به برنامه خودش پل‌ها رو پیدا می‌کنه و می‌پرسه باهاشون وصل بشه یا نه
